# Lucky Five Poker

Lucky Five Poker 是一款使用 **C# Windows Forms** 開發的五張牌撲克小遊戲。玩家可以下注、發牌、選擇換牌，最後系統會自動判斷牌型並依照賠率計算獎金。

## 專案特色

- 使用 Windows Forms 製作圖形化介面
- 支援五張牌撲克玩法
- 可進行下注、All-in、儲值
- 可選擇要更換的牌
- 自動判斷撲克牌型
- 依照牌型賠率計算獎金
- 具有破產判斷與儲值機制
- 介面包含牌桌、下注區、功能區與提示文字

## 遊戲玩法

1. 輸入下注金額。
2. 按下「下注」或「All In」。
3. 按下「發牌」取得五張手牌。
4. 點選想要更換的牌，被選到的牌會翻成背面。
5. 按下「換牌」後，系統會將背面的牌替換成新牌。
6. 按下「判斷牌型」。
7. 系統會顯示牌型、賠率、中獎金額與目前總資金。

## 功能說明

### 下注系統

玩家一開始擁有預設資金 `1000000`。  
每回合開始前必須先下注，下注成功後才可以發牌。

系統會檢查：

- 下注金額是否為數字
- 下注金額是否大於 0
- 下注金額是否超過目前總資金
- 遊戲進行中不可儲值

### All In

玩家可以按下「All In」，系統會自動將目前所有資金作為下注金額。

### 儲值系統

當玩家資金不足或破產時，可以輸入儲值金額並按下「儲值」。  
儲值金額必須大於 0，且遊戲進行中不可儲值。

### 發牌

按下「發牌」後，系統會：

1. 初始化 52 張牌。
2. 隨機洗牌。
3. 發出前五張牌給玩家。
4. 顯示對應的撲克牌圖片。
5. 啟用換牌功能。

### 換牌

玩家可以點選想換掉的牌。  
被選中的牌會翻成背面。  
按下「換牌」後，系統會用牌堆中的新牌取代被選中的牌。

### 牌型判斷

系統會依照五張手牌的點數與花色判斷牌型，包括：

- 皇家同花順
- 同花順
- 四條
- 葫蘆
- 同花
- 順子
- 三條
- 兩對
- 一對
- 雜牌

判斷完成後，系統會根據牌型取得賠率，計算獎金並更新玩家總資金。

## 測試快捷鍵

程式內建部分測試用快捷鍵，可用來快速產生特定牌型。

| 按鍵 | 測試牌型 |
|---|---|
| q | 同花大順 |
| w | 同花順 |
| e | 同花 |
| r | 鐵支 |
| t | 葫蘆 |
| y | 三條 |

> 注意：快捷鍵主要用於程式測試，實際遊戲時可不使用。
